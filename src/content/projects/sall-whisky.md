## Highlights

- **Real domain rules** - 3-year legal maturation check, volume-weighted ABV when a cask is filled from several distillations, automatic whisky-type classification, and re-barrelling that preserves full aging history
- **Two stacks, one domain** - JavaFX three-layer app with serialization storage, then Spring Boot 3.2 REST + Angular 17 with signals
- Spring Data JPA, HTTP Basic security, seeded data, DTO + repository patterns
